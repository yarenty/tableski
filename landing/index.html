Live market data work in progress

"Which of my holdings dropped below their 50-day average this week?" One question, one query over live bars and your own portfolio file.

  • Hourly and daily bars for a short list of symbols
  • Indicators as SQL: moving averages, RSI, MACD, Bollinger, drawdown
  • Joined with your own positions sheet, in one query
  • Read-only by construction: only SELECT-shaped queries run, with time and size limits

How to use it today

The engine is open source, one binary, MIT or Apache-2.0. It turns a file of prices, trades or positions into tables and serves them to any MCP client.

  1. Install

    One command on macOS or Linux; Windows binaries are on the releases page. Or cargo install tableski.

  2. Point it at a file

    An .xlsx, .csv or .parquet file: every sheet becomes a table with typed columns. Nothing leaves your machine.

  3. Connect your AI and ask

    Claude Code, Cursor, kowalski or any other MCP client. Ask in plain words; every answer shows the SQL it came from.

curl -fsSL https://raw.githubusercontent.com/yarenty/tableski/main/install.sh | sh
tableski --file positions.xlsx
claude mcp add --transport http tableski http://127.0.0.1:8080/

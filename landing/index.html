Three steps, about five minutes

Every sheet in your file becomes a table with proper columns and types. From then on, SQL does the work, whether you write it or an AI does.

  1. Add a spreadsheet

    Drop an .xlsx, .csv or .parquet file on the Files page. Cells are read, never executed. You see every table it produced, with row counts, before asking anything.

  2. Ask it something

    The Query page runs your first questions right in the browser. Click a table to see its rows, then try a total, a filter, a join across two sheets.

  3. Connect your AI

    Create a token and copy a ready-made setup for Claude Desktop, Claude Code, Cursor or kowalski. Then ask in plain words. The AI writes the SQL, tableski runs it on your file.

Which customers are more than 60 days late, and how much do they owe in total?

Four customers, €18,420 in total. Largest is Northwind Traders at €9,800, 74 days.

The AI turned that into one query over your invoices sheet and ran it here:

SELECT customer, sum(amount) AS owed, max(days_late) AS days
FROM invoices
WHERE days_late > 60
GROUP BY customer
ORDER BY owed DESC

Why it works

Computed, not guessed

The AI never reads your cells into its memory and adds them up in its head. It writes SQL; a real query engine computes the answer over every row.

Fast enough to talk to

A 100,000-row workbook answers in tens of milliseconds, a million-row CSV in well under a second. Measured, with numbers.

Read-only by construction

Only SELECT-shaped queries over your own tables run. Timeouts, row and memory caps, per-minute limits. How the guard works.

Your file stays yours

Nothing is written back into your workbook. Free files are removed after 24 hours; delete anything, or the whole account, at any time. Privacy.

Or run it yourself

The engine is open source, one binary, MIT or Apache-2.0. Point it at a file and connect any MCP client.

curl -fsSL https://raw.githubusercontent.com/yarenty/tableski/main/install.sh | sh
tableski --file your-workbook.xlsx
claude mcp add --transport http tableski http://127.0.0.1:8080/

tableski 🐧

Every spreadsheet is a table — tableski serves them to your agents in SQL.

Excel, CSV, Parquet, NDJSON → real SQL tables (Apache DataFusion), spoken over the Model Context Protocol. Joins across sheets and formats, typed columns, results exported back to .csv/.xlsx. Single binary, hardened for real-world workbooks.

cargo install tableski
tableski --file your-workbook.xlsx
claude mcp add --transport http tableski http://127.0.0.1:8080/
